# Bank-landing

Концепт редизайна главной страницы Российско-Индийского делового совета (ribc.sber.bank.in)
в стиле lassie.ai.

- `site/index.html` — вся страница: разметка, стили и JS в одном файле, без сборки и зависимостей.
- `site/img/gref.jpg` — фото для карточки цитаты.

Фоны карточек — CSS-градиенты, логотип — временная заглушка, форма заявки никуда не отправляет
(только проверяет поля и показывает «Спасибо»).

Локальный просмотр:

```bash
cd site && python3 -m http.server 8767
```

затем http://localhost:8767

Хостинг на Render: Static Site, Publish Directory = `site`, Build Command пустой.
